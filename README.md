# AriaBot Panel (con login Leona + zoom 90%)

## Publicar en Vercel (2 pasos)
1. Instala la CLI (una vez):  `npm i -g vercel`
2. Desde esta carpeta:        `vercel --prod`
   (acepta los valores por defecto; framework detectado: Vite)

O en vercel.com → "Add New… → Project" → sube/arrastra esta carpeta.

## Desarrollo local
    npm install
    npm run dev

## Qué incluye
- Login / Registro / "Olvidé mi contraseña" con la marca Leona (idéntico a las capturas).
- Botón de tema (sol/luna) arriba a la derecha; modo claro y oscuro.
- Toda la interfaz al zoom 90% (html{zoom:.9}).
- El resto del panel (Dashboard, Chats, Flujos, Kanban, etc.) tras iniciar sesión.
